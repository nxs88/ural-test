## Запуск проекта

### Требования

- Демонстрационный API-ключ Favorit Parts из документации к тестовому заданию

### Установка

1. Клонируйте репозиторий.
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте в корне проекта файл `.env.local` на основе `.env.example`.
4. При необходимости укажите действующий API-ключ Favorit Parts в `.env.local`:

   ```env
   VITE_FAVORIT_API_KEY=ваш_демонстрационный_ключ
   ```

5. Запустите приложение:

   ```bash
   npm run dev
   ```

### Примечание

Для запросов используется демонстрационный API-ключ из документации к тестовому заданию. Доступность API и количество запросов могут зависеть от ограничений демонстрационного ключа.
